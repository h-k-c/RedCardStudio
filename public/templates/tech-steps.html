// Dev Tips

Git 工作流
5 个必会技巧

提升团队协作效率的核心操作

01

约定式提交

用 feat/fix/docs 前缀让 commit 语义化，自动生成 changelog

feat: add login validation
02

交互式 Rebase

合并碎片 commit，保持主线历史干净可读

03

善用 Stash

临时保存工作区，快速切换分支处理紧急任务

git stash push -m "wip: feature"
04

Cherry-pick 精准移植

只摘取需要的 commit 到目标分支，不引入无关代码

05

Bisect 定位 Bug

二分查找法快速定位引入问题的 commit

@your_handle 01/05
